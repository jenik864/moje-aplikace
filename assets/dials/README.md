# Rank material atlas

Generated for Quitter using the image generation tool. This is bundled local artwork, not a remote image service. No numerals or clock hands are embedded; actual timing and text are native UI overlays.

The PNG is a precise 3-column × 4-row grid of equal square cells. Keep this layout when replacing the asset. The renderer clips the selected cell at runtime.

Row-major order: Copper, Bronze, Iron; Silver, Gold, Platinum; Sapphire, Amethyst, Ruby; Emerald, Diamond, Obsidian. Rank names and thresholds remain defined by `src/model.ts`.

Clock typography: Space Grotesk 500/600, distributed through `@expo-google-fonts/space-grotesk` under its bundled SIL Open Font License. Font files are loaded locally by Expo Font.
